大二暑假我參加了校內 Intelligent Mobile Application Club（I.M.A.C）實驗室的 iOS 開發暑期實訓，靠著實際動手做 UI 元件和設計模式來學習行動開發。

- 以 MVVM 設計天氣 App，串接氣象 API、Realm 資料庫與 MapKit
- 以 MVC 設計銀行 App，實作生物辨識驗證、通知推播與即時匯率顯示
- 用 Storyboards、SwiftUI 等 Swift 介面佈局系統，搭配 Swift5 開發
